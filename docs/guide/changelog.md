# Changelog

The changelog is generated from the [Conventional Commits](https://www.conventionalcommits.org) history by
[git-cliff](https://git-cliff.org) (configuration in `cliff.toml`) at release time: `scripts/release.sh` regenerates
`CHANGELOG.md` in the repository root for every new version, and its content will be shown on this page.

Until then, the history of the releases is on the
[GitHub releases page](https://github.com/Fortran-FOSS-Programmers/FOODIE/releases).
